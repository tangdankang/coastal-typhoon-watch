## 数据来源与字段

来源：[浙江省水利厅台风路径实时发布系统](https://typhoon.slt.zj.gov.cn/)。接口路径从官方首页实际加载的公开脚本确认，2026-08-31 验证可匿名读取：

| 公开端点 | 用途 |
| --- | --- |
| `/Api/TyhoonActivity` | 活动列表，Tyhoon 是来源系统实际拼写 |
| `/Api/TyphoonList/{year}` | 年度列表；新年为空时再查上一年 |
| `/Api/TyphoonInfo/{tfid}` | 该台风的观测与预报详情 |

`tfid/name/enname` 是编号和名称；`lng/lat` 是经纬度；`speed` 是风速 m/s，`power` 是风力级数，`pressure` 是 hPa；`movespeed` 是移动速度 km/h，`movedirection` 是移动方向。不得把 speed 与 movespeed 混淆。无时区的来源时间按北京时间 UTC+8 解析，快照存 ISO UTC，界面统一显示北京时间。

预报只使用最新观测中 `tm = 中国` 的分组，保持来源值，不自行外推；过期观测不展示预报，历史非活动台风不显示已过时的预报。起报时间从分组原始时间读取。图形仅为坐标示意、非导航地图，不绘制自创风险圈。

这些端点属于网站公开实现，未找到面向第三方的正式开放 API 合约、再分发授权或服务等级保障。匿名可读取不等于官方合作/授权。本站标注来源、只按小时少量读取公开天气事实，不使用账号、Cookie、签名逆向或访问限制绕过。商业运营或进一步扩大发布前，应向来源方确认授权和持续供数安排；若来源明确限制使用，应暂停同步并改用获授权数据源。

## 预警边界

本轮仅接入台风路径资料，**未接入本地官方分级预警**。页面显示“本地预警状态未知”，提供官方入口。蓝黄橙红只用于颜色识别，不是当前预警。绝不依据台风中心风力、坐标、距离推算某地预警，也不把“未接入”表述为“无预警”或“安全”。

## 自动同步和故障行为

工作流 `.github/workflows/update-and-deploy.yml` 在默认分支 main 上每小时第 17 分钟计划运行，也支持 Actions → Update typhoon data and deploy Pages → Run workflow 手动运行。网页的“检查已发布更新”只读取本站快照，不直接请求浙江接口或触发 Actions。

同步顺序：安装锁定依赖 → 单元测试与类型检查 → 读取来源并校验 → 构建静态网页 → 校验发布产物 → 部署。单次 HTTP 请求超时 25 秒，最多 3 次有限重试；全部成功校验后才原子写出 JSON。错误、缺坐标、活动状态冲突、异常时间或格式变化会中止发布，保留上次成功部署的整个网站，不用演示内容替代。

- 网页每 5 分钟读取一次本站快照；每分钟重新判断过期状态。
- 最近成功抓取超过 150 分钟：显示数据过期，不能视为最新实况。
- 活动台风最新观测超过 6 小时：显示观测可能过期，隐藏预报。
- 上述阈值是本站显示策略，不是官方数据有效期保证。
- 无活动列表只有在成功校验到真正空数组时才显示；抓取错误不是无台风。
- 读取更新失败时保留已显示资料并明确提示，提醒查看官方系统。

[GitHub 官方调度说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)：定时任务可能延迟或被丢弃，不保证整点及时；公开仓库连续 60 天没有活动时定时工作流可能自动禁用。请定期检查 Actions，禁用后手动启用；本网站不能作为预警必达服务。流程不会通过定时提交“伪造活动”来规避该限制。

## 构建和维护

使用 Node.js 24，在 `web/` 运行：

```sh
npm ci
npm test
npx tsc --noEmit
npm run fetch:data
npm run build
npm run export:html
npm run build:pages
npm run test:pages
```

静态产物位于 `web/pages-dist/`。根页面使用相对路径 `./data/current.json`，兼容 GitHub 项目站点前缀。`web/public/data/` 和 `web/pages-dist/` 为生成目录，不提交到 Git。无须配置数据 API 密钥；Actions 使用 GitHub 自带的短期部署令牌，构建只有 contents:read，部署只有 pages:write 和 id-token:write。Actions 引用固定提交摘要。

现有 Sites/Vinext 结构和私有演示站不迁移、不删除。新增 `/live` 供本地预览，GitHub Pages 使用单独静态入口；公开页面不会依赖 Sites 登录。演示和实况有各自的分享图片、文案与数据来源。

如需暂停更新：在 Actions 中禁用此工作流，页面会随时间显示过期。如需完全下线：Settings → Pages → Unpublish site。不要将凭据、私人资料或不打算公开的文档提交到已公开的仓库。
