# 岸风｜演示网页交付说明

日期：2026-08-31

## 打开方式

在线访问：[岸风演示网页](https://coastal-watch-demo.f378402801.chatgpt.site)。访问权限保持为所有者私有，不是面向居民正式上线的公共服务。

离线访问：[单文件 HTML](../网页演示/index.html)。下载这个文件后，用现代浏览器打开并启用 JavaScript。样式、脚本和地理轮廓均已内嵌，不需要安装软件，也不需要实时网络接口。

## 已实现功能

- 台风名称、编号、中心经纬度、移动方向/速度、中心附近最大风力与气压面板。
- “青岚”“云汐”两组虚构台风切换，每组 5 个历史/当前演示点与 4 个模拟未来点。
- SVG 路径示意图：真实陆地轮廓辅助定位、实线历史、虚线模拟预报、当前点与关注城市标记。
- 可点击的路径点、地图缩放/复位、数据列表及历史轨迹回放。
- 时间轴选点；回放不改变上方固定的当前演示快照。
- 关注地区切换：宁波、福州、舟山、厦门分别配置黄、橙、红、蓝四种视觉样例；深圳使用“未设置预警样例”，不解释为无风险。
- 预警详情、颜色说明、数据说明对话框，以及跳转到真实官方预警查询的入口。
- 手机、电脑响应式布局；键盘选点、控件名称、焦点提示、减少动画偏好和文字轨迹替代。

## 数据与安全边界

全部台风名称、编号、位置、移动、风力、预警和预报点均为虚构演示数据。固定示例时刻为 2026-08-19 08:00（北京时间），不是当前天气，刷新不产生新的观测时间。

顶部横幅、台风选择区、地图、预警卡片、详情与页脚分别标注演示属性。预警没有虚构成气象台发布，也不会发送通知。中心风力与本地风力不混淆。未配置样例不代表该地区无真实预警或安全。

页面不采集精确定位、不要求账号手机号、不访问真实气象接口。在线访问权限由 Sites 托管层控制；离线 HTML 不含认证逻辑或个人数据。

底图仅为 Natural Earth 公有领域陆地轮廓，非导航地图，未绘制行政国界；地名用于示意。授权说明见 [Natural Earth Terms of Use](https://www.naturalearthdata.com/about/terms-of-use/)。分享预览使用本项目生成的品牌图片。

## 源码与维护

源码位于 `web/`。主要文件：

- `app/page.tsx`：页面布局与交互。
- `app/globals.css`：配色、组件样式和响应式规则。
- `lib/demo-data.ts`：固定演示台风、时间点和地区预警样例。
- `lib/land.json`：公有领域地理轮廓。
- `scripts/export-html.mjs`：从构建产物和应用入口生成离线 HTML。
- `scripts/demo-data.test.ts`：数据边界及类型语义测试。

在 `web/` 中执行 `npm ci` 安装锁定依赖，`npm run dev` 启动开发；`npm test` 检查样例，`npm run build` 构建，`npm run export:html` 重新生成离线文件。不要手动修改生成的 HTML 来替代源码维护。
