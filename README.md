# 海岸台风信息站

面向沿海居民的台风实况、路径预报与官方分级预警信息网站。

当前阶段：交互式演示网页。已经实现台风面板、路径示意图与预警卡片；全部使用虚构固定数据，尚未接入真实气象数据。

- [在线演示（仅所有者可访问）](https://coastal-watch-demo.f378402801.chatgpt.site)
- [离线单文件 HTML](网页演示/index.html)：下载后用浏览器打开即可，无需安装；网页运行不依赖网络，只有主动打开官方资料链接时需要联网。

## 产品要回答的问题

1. 台风叫什么？
2. 现在在哪里？
3. 接下来往哪走？
4. 风力有多大？
5. 我所在地区有什么官方预警，应查看哪些防御指引？

## 关键边界

- 本站定位为信息展示与传播服务，不自行发布气象预报或官方预警。
- 台风中心风力与居民所在地风力分别展示；历史实况与未来预报分别标识。
- 正式数据接入必须先确认授权、覆盖范围、更新周期和解除预警机制。
- 数据缺失、过期或接口故障不得解释为“无台风”“无预警”或“安全”。
- 计划以中国大陆沿海居民为首期对象；具体试点地区、预算和数据供应方尚待确定。
